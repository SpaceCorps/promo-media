# SpaceCorps 2027 promo media

Finished promo videos and picture posts of [SpaceCorps 2027](https://play.spacecorps.tech/), kept here so the
publishing service can fetch them by link. Files are attached to releases:

- `v<version>`: the promo video of that game update (vertical and landscape);
- `cards`: picture posts;
- `weekly-<week>`: the weekly video.
